# Velvet Fling
An original, offline, flirty gothic Android slingshot arcade game.
Five handcrafted levels, touch-drag aiming, jewel physics, chain reactions, gargoyles, animated art, sound effects, score persistence and no ads.
This branch is isolated from Nova Starfall Defense. The application ID is com.novasky.velvetfling.
Built with Java + Android WebView + local Canvas JavaScript; no network permissions or external libraries.
Build with `gradle :app:assembleDebug`. Debug builds are Android-signed for installation.
