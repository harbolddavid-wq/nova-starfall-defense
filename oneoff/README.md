# Nebula Swarm — one-off scheduled-task APK experiment

**An original offline fixed-shooter for Android 8.0+ (API 26+), targeting Android 15/16.**

Package: `com.novasky.nebulaswarm` • version `0.1.0` • private debug build.

## Play
Launch the app, tap **LAUNCH MISSION**, drag horizontally to steer. Auto-fire starts enabled. Toggle **AUTO FIRE** in the bottom-left; hold **FIRE** to shoot manually. Collect falling green cores for hull repairs and gold cores for 10 seconds of triple-shot. Tap the top-right pause icon to pause/resume, or the musical note to mute. Survive successive waves; every fourth wave includes an Archon flagship. Best score is stored locally on the phone. No network access, accounts, ads, telemetry, or special permissions.

## Build
Open `oneoff/` as an Android Gradle project or run `gradle :app:assembleDebug` inside that directory with JDK 17, Gradle 8.13, Android SDK Platform 36 and Android Build Tools 35.0.0. Result: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions workflow `.github/workflows/oneoff-nebula-swarm.yml` compiles and verifies the APK and uploads build and source artifacts.

## Implementation
Native Java Android Activity hosting a full-screen offline HTML Canvas game. Entire game, vector graphics, particles, scrolling starfield, and sound synthesizer are original code. Sound effects are procedurally synthesized with Web Audio at runtime (no copyrighted samples). Artwork is drawn procedurally in Canvas and an original vector launcher icon; no external dependencies, remote fonts, or third-party assets. The Android shell uses the platform WebView.

## Test notes
Compilation and signature checks are separate from Android emulator and physical-device testing. See `TEST_REPORT.md` for actual verified test results. The private debug signing key is generated by the build environment and may differ between builds. Do not install a future differently signed APK over this build without uninstalling the old test app.
