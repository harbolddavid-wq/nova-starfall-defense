# Nova Afterglow

A private offline music and video player commissioned by David. The player uses LibVLC for broader codec/container support, the Android document picker for explicitly chosen files or folders, and a playback service for screen-off audio. No player can guarantee every possible or protected format. See `WORKLOG.md` for the actual checkpoint and verified limitations.

Source builds deliberately do not contain David's privately supplied art. The personal APK overlays selected adapted Neptune, HumblePixel and Kronbits assets into the app before signing; `ART_CREDITS.md` documents provenance. Source files, private signing material and original source packs must remain separate. LibVLC by VideoLAN is LGPL; see https://github.com/videolan/vlc-android and https://www.videolan.org/vlc/libvlc.html.
