# Starlight Icons (native Android)
Long-press an installed app's icon inside Starlight Icons, choose one of sixty built-in designs or draw/import your own, then tap Add to Home. Android Launcher will request confirmation to pin a custom shortcut to that app.
The original installed app icon and app drawer entry do not change. No Galaxy Store extra app needed. No ads or internet permission.
Android minSdk 26, target 35. Build: gradle :app:assembleDebug. This is the first native beta; on-device Samsung launcher acceptance needs testing.
