# Starlight Themes for Desi — early launcher work

This is a separate offline Android Home project for Desi's Samsung Galaxy A17 5G. The core goals are familiar multi-page navigation, draggable shortcuts, folders and a fixed dock, a conventional searchable app drawer, optional individual icon styles and preview-first theme selection. Choosing Android Home is voluntary; Samsung Home's existing layout is not modified. Theme selection is stored independently from the layout.

The current source is an early preview, not a finished launcher. The 0.4 preview responds to Desi's feedback: themed icon artwork is automatic for recognized categories, with a small original-app mark for recognition; other apps receive a coordinated frame containing their original icon. Themed icons can be turned off or customized per app. New installations seed only familiar dock suggestions and offer a favorites picker for the home page, rather than populating arbitrary apps. Existing layouts are kept on update; choosing favorites explicitly replaces the current page's available app shortcuts and supports immediate undo.

Home icons can be dragged directly; an ordinary occupied drop swaps and pausing over an icon creates a folder. Folder icons and opened folders use a library shelf design with clearly labeled apps. Widgets can be moved by holding and dragging, or through Home options → Widgets; resizing stays in the menu and respects available space and provider dimensions. Interrupted widget setup can be continued or cancelled, and placement is saved together with pending-state cleanup. The manifest declares a scoped widget-provider query for modern Android.

These flows need automated interaction testing and feedback on Desi's actual device. Page reordering, configurable grid, complete backup/restore, launcher shortcuts, richer appearance options, accessibility and real-phone usability/performance validation remain unfinished. See the current handoff in `/App Ideas/Starlight_Themes_Desi_Familiar_Android_Launcher_Concept.md`.

Package: `com.novasky.starlightthemes`, min API 26, target API 35. The source has no internet permission and never changes the system wallpaper. `scripts/build-android.py` creates an unsigned APK with the Android SDK, while `scripts/apply_private_art.py` adds only selected personal artwork; sign locally with the dedicated private key. The private key and personal artwork never belong in this public source branch. `ART_CREDITS.md` records the source and prompts. Run `WorkspaceModelTest` on Java 17 for page/folder/drag invariants; this does not replace Android runtime or Desi's playtesting.
